## Recent
[chat] "Tabs where each tab is a collection" means a tabs-and-sliding-panels widget in ONE section (tab block has its own collection picker, panel below the bar swaps between collections on click). It does NOT mean a scroll-spy nav that anchor-jumps to separately stacked product-list sections — that pattern feels like tabs from above but doesn't match the design intent of "click slides to show that collection".
[chat] A section cannot mix theme blocks (`{% content_for 'block', type: '_product-card' %}`) with section-defined blocks in its schema — Shopify errors with "Theme blocks and section-defined blocks can not be used together". For sections that need both custom block types (e.g. tab) AND product rendering, inline the product card HTML using `{% for product in block.settings.collection.products %}` plus `{% render 'price' %}`, instead of trying to reuse the `_product-card` theme block.
